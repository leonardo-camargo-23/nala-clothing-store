# nala-clothing-store

Tienda web de ropa y accesorios, nuevos y de segunda mano (vintage), con pagos en línea. Proyecto en construcción.

## Stack

- **Backend:** Java 21, Spring Boot 3, Maven, PostgreSQL y Flyway
- **Frontend:** Next.js con TypeScript
- **Pagos:** pasarela por definir; la arquitectura permitirá añadir varias

## Estado

En construcción: fase 0 (repositorio y entorno).
